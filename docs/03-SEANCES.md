# Séances privées

## Objectif
Cash rapide, agenda rempli, témoignages et preuve locale.

## Positionnement
Ne pas vendre une séance comme un massage spa classique.

Le French Body Reset est un travail manuel profond, précis et personnalisé centré sur les tensions ressenties, la mobilité, le relâchement, la récupération et l’aisance corporelle.

## Situations principales
- dos chargé ;
- nuque raide ;
- épaules tendues ;
- lombaires / bassin / hanches ;
- jambes lourdes ;
- stress accumulé ;
- fatigue nerveuse ;
- récupération après voyage, sport, surf ou ordinateur.

## Funnel
WhatsApp → qualification → créneau → réservation → paiement → séance → témoignage → relance.

## Qualification WhatsApp
Demander :
1. zone de tension / besoin principal ;
2. depuis quand ;
3. ville / quartier / lieu ;
4. urgence : aujourd’hui, cette semaine ou plus tard.

## CTA prioritaire
Demander une séance cette semaine / WhatsApp direct.

## Post-séance
- demander un témoignage ;
- demander autorisation d’utilisation photo/vidéo si applicable ;
- taguer source, ville, offre et résultat commercial dans GHL ;
- programmer la relance adaptée.
