## Règles
- une page locale seulement si l’offre est réelle ou planifiée ;
- chaque landing locale doit préciser ville, langue, disponibilité, CTA et preuve ;
- trafic froid : landing courte et directe ;
- trafic premium / institutionnel : gregorytordjman.com ;
- formation : formationreboutement.fr ;
- ne pas mélanger Oracle Lumira avec cet écosystème.
