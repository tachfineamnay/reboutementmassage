# B2B & Hospitality

## Objectif
Créer des partenariats premium, récurrents et locaux.

## Cibles prioritaires
- hôtels ;
- villas ;
- conciergeries ;
- yachts ;
- spas ;
- retraites ;
- surf camps ;
- yoga studios ;
- salles de sport ;
- entreprises ;
- événements.

## Interlocuteurs à viser
Spa Manager, General Manager, Concierge Manager, Villa Manager, Retreat Manager, Wellness Director ou responsable RH selon le cas.

## Offre centrale
**TMS Hotel & Retreat Experience** : intervention manuelle discrète et personnalisée pour clients ou équipes, sans logistique lourde.

## Cas d’usage
- client après long vol ;
- dos / nuque chargés ;
- fatigue corporelle ;
- récupération après surf, sport ou mer ;
- équipe spa / hospitality sous tension ;
- atelier entreprise ou événement.

## Funnel
Prospect identifié → contacté → réponse reçue → offre test → RDV → intervention → partenariat → relance.

## Offre test recommandée
Proposer une première intervention ou démonstration ciblée avant de discuter partenariat récurrent.

## KPI
Contacts qualifiés, taux de réponse, RDV, tests réalisés, propositions envoyées, partenariats actifs, valeur mensuelle et récurrence.
