## Body Reset Fix

### Positionnement
Séance privée pensée pour les personnes qui ressentent une tension claire, un corps chargé ou un besoin rapide de relâchement.

Situations citées dans l’offre source :
- dos lourd ;
- nuque raide ;
- épaules bloquées ;
- fatigue corporelle accumulée ;
- sensation que le corps a besoin d’un reset.

### Durée
**Environ 75 minutes.**

### Déroulé documenté
1. Lecture du corps.
2. Travail manuel profond, précis et personnalisé.
3. Priorisation des zones qui se présentent ce jour-là.

### Objectif marketing autorisé
Aider le corps à :
- relâcher les tensions ;
- retrouver plus de mobilité ;
- repartir avec une sensation de clarté, d’aisance et de légèreté.

Ce n’est pas présenté comme un massage classique.

## French Body Reset Full

### Positionnement
Protocole complet pour les personnes qui souhaitent un travail de reset corporel plus progressif et plus profond qu’une séance ponctuelle.

### Durée
- **3 séances privées** ;
- **environ 75 minutes chacune** ;
- réparties sur **2 à 4 semaines**, selon le rythme et les besoins.

### Déroulé documenté

**Séance 1**
- lecture du corps ;
- compréhension des tensions principales ;
- début d’un reset global.

**Séance 2**
Travail plus approfondi selon ce que le corps présente, notamment :
- dos ;
- nuque ;
- épaules ;
- bassin ;
- hanches ;
- jambes.

**Séance 3**
- intégration du travail ;
- stabilisation des sensations ;
- conseils simples pour prolonger les effets.

### Accompagnement documenté
Le travail est **adapté à l’évolution du corps entre chaque séance**.

La source documente aussi des **conseils simples à la troisième séance**.

En revanche, elle ne documente pas explicitement :
- un suivi WhatsApp entre les séances ;
- une disponibilité 7j/7 ;
- un nombre de messages ou appels inclus ;
- des exercices écrits ou vidéos envoyés entre chaque rendez-vous.

Ces éléments doivent être définis avant d’être vendus comme inclus.
