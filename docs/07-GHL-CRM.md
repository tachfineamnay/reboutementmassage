# GHL / CRM / WhatsApp

## Rôle
GHL est la mémoire commerciale : contacts, opportunités, pipelines, tags, booking, relances, WhatsApp et conversion.

## Pipeline — Séances
Nouveau lead → À qualifier → Créneau proposé → Réservé → Payé → Séance faite → Témoignage demandé → À relancer

## Pipeline — Formation
Nouveau lead → Ressource envoyée → RDV proposé → RDV réservé → Offre envoyée → Paiement en attente → Inscrit → Upsell

## Pipeline — B2B
Prospect identifié → Contacté → Réponse reçue → Offre test → RDV prévu → Partenariat en discussion → Partenaire actif → À relancer

## Données critiques
Toujours enregistrer source, canal, ville, campagne, offre, statut, réservation, paiement et témoignage.

## Règle
Ne jamais envoyer de données de santé détaillées ou de texte libre sensible aux plateformes publicitaires. Utiliser des catégories larges : dos, nuque, fatigue, stress, mobilité, autre.
